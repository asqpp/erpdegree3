## 🚀 DEPLOYMENT GUIDE

### Prerequisites:
- PHP 7.4+
- MySQL 5.7+
- Node.js 14+
- Apache/Nginx web server

### Installation Steps:

#### 1. Database Setup (5 minutes)
```bash
cd /home/user/erpdegree3/database
mysql -u root -p erpdegree < MASTER_MIGRATION.sql
```

#### 2. UI Build (3 minutes)
```bash
cd /home/user/erpdegree3
npm install
npm run build
```

#### 3. Web Server Configuration
Point your web server to `/home/user/erpdegree3/`

#### 4. Access Application
```
http://localhost/erpdegree3/dashboard
```
